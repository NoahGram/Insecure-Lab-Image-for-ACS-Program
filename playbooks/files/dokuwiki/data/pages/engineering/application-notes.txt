===== IoT & Wireless =====

==== AN001: Building a BLE Sensor Node with LS-1020 ====

**Abstract**: This application note demonstrates how to build a battery-powered environmental sensor using the LS-1020 with integrated BLE 5.0.

**Key Topics**:
  * Low-power design achieving 2+ year battery life on CR2032
  * Temperature, humidity, and pressure sensor integration (I2C)
  * BLE advertising and GATT service configuration
  * OTA firmware update implementation

**Performance Results**:
| **Mode**           | **Current** | **Duration**        |
| Deep Sleep         | 0.8 µA      | 99.5% of time       |
| Active (sampling)  | 3.2 mA      | 50 ms per sample    |
| BLE TX (0 dBm)     | 8.5 mA      | 2 ms per advertisement |

**Average Power**: 12 µA @ 1 sample/minute + advertising

**Code Example**:
<code c>
#include "labsys_ble.h"
#include "labsys_i2c.h"

void sensor_task(void) {
    float temp = read_temperature();  // I2C sensor
    float humidity = read_humidity();
    
    // Update BLE characteristic
    ble_update_sensor_data(temp, humidity);
    
    // Return to deep sleep
    enter_deep_sleep(WAKEUP_RTC, 60000);  // 60 second sleep
}
</code>

==== AN010: Object Detection with LS-2020 ====

**Abstract**: Deploy a YOLOv5 object detection model on the LS-2020 AI accelerator for real-time inference.

**Key Topics**:
  * Model conversion from PyTorch to LabSys format
  * INT8 quantization with minimal accuracy loss
  * Camera input via MIPI CSI
  * Post-processing and visualization

**Performance Results**:
| **Model**        | **Resolution** | **FPS** | **Power** | **Accuracy (mAP)** |
| YOLOv5n (INT8)   | 640x640        | 45      | 5.2W      | 28.0               |
| YOLOv5s (INT8)   | 640x640        | 28      | 6.8W      | 37.2               |
| YOLOv5m (INT8)   | 640x640        | 12      | 7.5W      | 44.5               |

**Conversion Command**:
<code>
lsnpu convert --input yolov5s.onnx \
              --output yolov5s.lsm \
              --quantize int8 \
              --calibration coco_cal_images/
</code>
