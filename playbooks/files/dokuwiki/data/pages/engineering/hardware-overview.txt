==== Pinout Summary (LS-1030, QFN-48) ====

| **Pin Range** | **Function**                              |
| 1-4           | Power (VDD_CORE, VDD_IO, VSS)             |
| 5-12          | GPIO Bank A (PA0-PA7)                     |
| 13-20         | GPIO Bank B (PB0-PB7)                     |
| 21-24         | SPI0 (CLK, MOSI, MISO, CS)                |
| 25-26         | I2C0 (SDA, SCL)                           |
| 27-29         | UART0 (TX, RX, RTS)                       |
| 30-33         | ADC Inputs (ADC0-ADC3)                    |
| 34-37         | BLE RF (ANT, RFVDD, RFGND, XTAL)          |
| 38-40         | Boot Config / Debug (SWDIO, SWCLK, nRST)  |
| 41-48         | GPIO Bank C / Alternate functions         |
| EP            | Exposed Pad (connect to GND)              |
