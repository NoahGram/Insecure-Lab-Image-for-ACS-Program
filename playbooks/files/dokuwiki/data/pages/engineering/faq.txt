===== Hardware Questions =====

**Q: What debug probes are compatible with LabSys chips?**

A: The following debug probes are supported:
  * LabSys Debug Probe (recommended, $35)
  * SEGGER J-Link (all versions)
  * CMSIS-DAP compatible probes
  * ST-Link (with adapter)

All probes connect via SWD interface (SWDIO, SWCLK, GND, VRef).

----

**Q: What is the recommended power supply for LS-1000 series?**

A: Power requirements depend on the model:

| **Model**  | **Core Voltage** | **IO Voltage** | **Recommended Regulator**|
| LS-1010    | 1.8V ± 5%        | 3.3V ± 10%     | LDO, 100mA               |
| LS-1020    | 1.8V ± 5%        | 3.3V ± 10%     | LDO, 150mA               |
| LS-1030    | 1.8V ± 5%        | 3.3V ± 10%     | LDO, 200mA               |

Use low-noise LDOs with <30mV ripple. Place decoupling caps (10µF + 100nF) close to VDD pins.

----

**Q: How do I put the chip in programming mode?**

A: Boot mode is selected via BOOT pins at power-on/reset:

| **BOOT[1:0]** | **Mode**           |
| 00            | Internal Flash     |
| 01            | UART Bootloader    |
| 10            | SPI Flash Boot     |
| 11            | USB DFU Mode       |

For development, use SWD programming without changing boot pins.

----

**Q: Are automotive-qualified parts available?**

A: Yes, automotive-grade (AEC-Q100) parts are available for:
  * LS-1030-A (Grade 2: -40°C to +105°C)
  * LS-2020-A (Grade 2: -40°C to +105°C)
  * LS-3020-A (Grade 1: -40°C to +125°C)

Contact automotive@labsys.com for automotive-specific documentation and pricing.

===== Software Questions =====

**Q: What compilers are supported?**

A: LabSys IDE includes the recommended GCC ARM toolchain. Other supported compilers:
  * GCC ARM Embedded (11.x, 12.x)
  * IAR Embedded Workbench (8.x, 9.x)
  * Keil MDK (5.x)

Linker scripts and startup files for all compilers are in the Firmware Library.

----

**Q: How do I update firmware over-the-air (OTA)?**

A: OTA update is supported on LS-1020/1030 with BLE:
  - Include the OTA bootloader in your build (labsys_ota library)
  - Reserve flash space for two firmware images (A/B slots)
  - Use the LabSys Connect mobile app or custom BLE implementation
  - Refer to Application Note AN005 for complete implementation

----

**Q: What RTOS options are available?**

A: The following RTOS ports are provided in the Firmware Library:
  * FreeRTOS (recommended)
  * Zephyr RTOS
  * ThreadX
  * Bare-metal (no OS)

FreeRTOS is fully integrated with LabSys IDE and includes tickless idle support for low-power applications.

----

**Q: How do I debug NPU models on LS-2000 series?**

A: NPU debugging tools include:
  * **ChipSim**: Cycle-accurate simulation with performance counters
  * **NPU Profiler**: Layer-by-layer timing and memory analysis
  * **Runtime Debug**: Real-time monitoring via JTAG
  
Use ''lsnpu profile --model model.lsm --chip LS2020'' to analyze performance before deployment.
