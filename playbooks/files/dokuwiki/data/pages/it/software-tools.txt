====== IT: Approved Software List ======

This page lists software approved for installation on LabSys corporate devices. Installing unapproved software is prohibited per the :it:security policy.

----

===== How to Request Software =====

  - Check if software is on the approved list below
  - If approved, submit installation request via IT Helpdesk
  - If not listed, submit a Software Approval Request form

**IT Helpdesk**: it-support@labsys.com

===== Prohibited Software =====

The following categories are **not permitted** on LabSys devices:
  * Personal cloud storage (Dropbox, personal Google Drive, iCloud)
  * Unauthorized remote access tools (TeamViewer, AnyDesk personal)
  * Torrent clients
  * Personal VPN services
  * Cryptocurrency mining software
  * Unapproved communication apps

Violations will be reported to HR and may result in disciplinary action.
